# AI-Проект для института классификации изображений с использованием PyTorch

Этот проект демонстрирует создание, обучение и тестирование сверточной нейронной сети (CNN) для классификации изображений с использованием библиотеки PyTorch. Проект включает в себя загрузку данных, определение модели, обучение и тестирование с визуализацией результатов.

## Структура проекта

- `main.py`: Основной скрипт для запуска обучения или тестирования модели.
- `model.py`: Определение архитектуры модели CNN.
- `train.py`: Функция для обучения модели.
- `test.py`: Функция для тестирования модели с визуализацией результатов.
- `mnist/`: Директория для хранения данных (тренировочных и тестовых).

## Команды

- `python main.py train` - для тренировки модели

- `python main.py test` - для тренировки модели

## Пояснение каждого файла

- **`main.py`**: Точка входа для запуска обучения или тестирования модели. Использует `argparse` для выбора режима (обучение или тестирование) и загрузки данных. Вызывает функции из `train.py` или `test.py` в зависимости от режима.

- **`model.py`**: Определяет архитектуру модели CNN с двумя сверточными слоями, функцией активации ReLU и слоем максимального пулинга, за которыми следуют два полносвязных слоя для классификации изображений.

- **`train.py`**: Содержит функцию `train_model` для обучения модели. Использует `tqdm` для отображения прогресса обучения и сохраняет обученную модель в файл `model.pth`.

- **`test.py`**: Содержит функцию `test_model` для тестирования модели. Выводит точность модели для каждой итерации и среднюю точность. Отображает примеры изображений с предсказанными и истинными классами с помощью `matplotlib`.
